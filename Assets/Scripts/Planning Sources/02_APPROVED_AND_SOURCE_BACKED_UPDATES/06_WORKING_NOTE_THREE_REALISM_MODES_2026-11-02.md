# Working Design Note #001 — Three realism modes (2026-11-02)

**Classification:** USER DESIGN PREFERENCE. **Not** a fully specified ruleset or independently approved implementation design.

- **Video Game Realism:** easier, more conventional management game conveniences and possibly simplified rules; scope still to be designed.
- **Land & Ledgers Realism (default preference):** full physical/economic simulation with selected player-information conveniences; user suggested readily visible current financial/operating information about **owned businesses**, even at distance. This is a **player UI knowledge policy**, not license to reveal all private NPC firm data.
- **Historical Realism:** preserve the same world state but restrict remote knowledge by historically available communications, report authorship, travel time, correspondence, messengers, telegram and information uncertainty. A distant business does not telepathically transmit current books.

**Open:** exact differences, permissions, whether toggles may change mid-campaign, save migration, degrees of historical information lag and test requirements. Do not build three parallel economies or override original Canon's NPC evidence/knowledge limitations.
