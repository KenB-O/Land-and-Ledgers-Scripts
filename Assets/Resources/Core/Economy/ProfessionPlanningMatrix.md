# Profession Planning Template

Every profession/business should be planned before implementation with these fields:

- Name
- Town-scale fit: start town, near-term, mid-growth, rail-era
- Archetype: goods-transformer, service-throughput, logistics/movement
- Thin/full form: frontier starter form or later mature form
- Building/site fit
- Staffing roles
- Operating rhythm
- Raw inputs
- Service inputs
- Outputs/services
- Primary customers
- Secondary customers
- Recurring local order hooks
- Household demand hooks
- Key dependencies
- Degraded/failure mode
- Continuity requirements
- Reputation dimensions
- Player-facing policies/actions
